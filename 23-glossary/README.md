## 💫 Sample Terms

### A
- **API**: Application Programming Interface
- **Authentication**: Verifying identity
- **Authorization**: Checking permissions
- **Abuse**: Misusing a feature

### B
- **Bounty**: Money for finding bugs
- **Burp Suite**: Web hacking tool
- **Buffer Overflow**: Memory exploit
- **Backdoor**: Unauthorized access

### C
- **CVSS**: Vulnerability severity score
- **CWE**: Common Weakness Enumeration
- **Cryptography**: Encryption science
- **Ciphertext**: Encrypted text

### S
- **SQL Injection**: Database exploitation
- **SSRF**: Server-side request forgery
- **XSS**: Cross-site scripting
- **CSRF**: Cross-site request forgery
