# 🔒 Security Policy

**Vulnerability Report Karne Ke Liye Guide**

---

## 🚨 Agar Koi Vulnerability Find Karo

### ❌ Mat Karo:
- GitHub issue mein publicly report mat kar
- Twitter par nahi share kar
- Doosre ko batane se pehle company ko inform kar

### ✅ Karo:
1. **Email send karo:** security@example.com
2. **Describe karo:**
   - Vulnerability type
   - Location (URL/file path)
   - Impact
   - Proof of concept
   - Suggested fix

3. **Wait karo:**
   - 24-48 hours response
   - 30-90 days fix timeline
   - Phir public disclosure
