## 🚫 Consequences

### First Violation
- Warning message
- Explanation of issue
- Chance to improve

### Second Violation
- Comment/post removal
- Temporary mute
- Clear expectations

### Third Violation
- Temporary ban (1-3 weeks)
- Final warning

### Severe Violation
- Immediate ban
- If illegal: Report to authorities
