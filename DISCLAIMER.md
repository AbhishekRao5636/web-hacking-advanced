## 📞 Reporting a Vulnerability

### Agar koi Vulnerability Mila:

**Step 1: Find Security Email**
```
https://website.com/.well-known/security.txt
or
security@website.com
or
bugs@website.com
```

**Step 2: Write Professional Report**
```
Subject: Security Vulnerability Report - [Type]

Hi Security Team,

1. Vulnerability: [Type]
2. Location: [URL/Path]
3. Severity: [High/Medium/Low]
4. Impact: [What can happen]
5. Proof: [Screenshot/Video]
6. Reproduction: [Steps]
7. Suggested Fix: [Solution]

Regards,
[Your Name]
```

**Step 3: Wait**
- Most companies respond in 24-48 hours
- Fix timeline: 30-90 days
- Patience rakhna!

**Step 4: Follow Up**
- 7 days baad: Follow up karo
- 30 days baad: Again follow up
- 90 days baad: Public disclose kar sakte ho

## 🚨 Red Flags - Mat Karo!

❌ **Social Engineering**
- Kisi ko fake call mat de
- Kisi ka password mat mange

❌ **Data Theft**
- User data download mat kar
- Personal information leak mat kar

❌ **Malware**
- Malware upload mat kar
- Virus plant mat kar

❌ **Denial of Service**
- Server ko crash mat kar (DDoS)
- Service disable mat kar

❌ **Unauthorized Access**
- Admin panel access ke liye mat try
- Other users' accounts mat access kar
