## 🚀 How to Contribute

### Step 1: Fork Repo
```bash
# GitHub pe "Fork" button click karo
```

### Step 2: Clone Kar
```bash
git clone https://github.com/YOUR_USERNAME/web-hacking-advanced.git
cd web-hacking-advanced
```

### Step 3: Create Branch
```bash
# Descriptive name dedo
git checkout -b add-xss-payloads
# or
git checkout -b fix-sql-typos
# or  
git checkout -b new-recon-guide
```

### Step 4: Make Changes
```bash
# Files edit karo
# New files add karo
# Content likho
```

### Step 5: Commit Karo
```bash
git add .
git commit -m "feat: Add XSS payload collection"
# or
git commit -m "fix: Correct SQL injection example"
# or
git commit -m "docs: Add Nuclei templates guide"
```

### Step 6: Push Karo
```bash
git push origin add-xss-payloads
```

### Step 7: Pull Request Likho
- GitHub par "Create Pull Request" click karo
- Title likho: "Add XSS Payload Collection"
- Description likho:
  - Kya add kiya
  - Kyon important hai
  - Screenshots/examples

### Step 8: Wait for Review
- Maintainers will review
- Feedback denge
- Changes suggest kar sakte hain
- Merge ho jayega!

---

## 📝 Commit Messages Format

### Use Conventional Commits:

```
type(scope): subject

body
```

### Types:
- `feat:` New feature/content
- `fix:` Bug fix
- `docs:` Documentation
- `style:` Formatting
- `refactor:` Code/content restructure
- `test:` Tests
- `chore:` Maintenance

### Examples:
```bash
feat(sql-injection): Add WAF bypass payloads
fix(xss): Correct DOM-based XSS example
docs(readme): Update getting started section
refactor(structure): Reorganize vulnerability categories
```
